# 6-build — 구현

자율 구현 단계입니다. `dev` 브랜치에서 진행하고, 끝나면 `master`에 머지합니다.

## 규칙

- **스펙을 고치지 않는다.** 스펙과 달랐던 것, 스펙이 몰랐던 것, 스펙이 정하지 않아 구현이 고른 것은 여기에 기록한다. 스펙 개정은 7-review에서 다음 시대로 넘긴다.
- **멈추지 않는다.** 멈춰야 한다는 생각이 들면 확신을 다시 점검하고, 놓친 것을 찾고, 그래도 5-preflight의 멈추는 조건에 해당할 때만 멈춘다.
- **판단 기준은 `CLAUDE.md`에 있다.** 사소한 것은 권장 선택, 중요한 것은 최선의 선택과 되돌리기 싼 선택을 놓고 독립 서브에이전트의 탐색 보고로 가치를 재서 고른다.
- **P마다 커밋하고 P마다 기록한다.**

## 기록 형식

P마다 파일 하나: `P<n>_<이름>.md`. 담는 것은 06 §14.1과 같다 — 스펙과 달랐던 것, 스펙이 몰랐던 것, 임시 형식에서 불편했던 것, 그리고 구현이 내린 판단과 그때의 확신 수준.

P0의 기록은 [`../5-preflight/06b_built_prototype.md`](../5-preflight/06b_built_prototype.md)에 있습니다. P1부터 여기에 씁니다.
