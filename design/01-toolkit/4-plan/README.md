# 4-plan — 계획

이 시대의 계획은 별도 문서가 아니라 스펙 안에 있습니다. 스펙과 계획을 함께 쓰던 시기의 기록이라 옮기지 않습니다.

- **프로토타입 계획 P0~P7:** [`../3-spec/06_toolkit_spec.md`](../3-spec/06_toolkit_spec.md) §14
- **결정 현황(정해진 것 / 열린 것):** 같은 문서 §16
- **검증 단계로 가는 길:** 같은 문서 §15

계획의 골자: 구체에서 시작해 추상으로 간다. 스키마를 먼저 설계하지 않고 P1~P3 실물 셋에서 P4에 역산하며, 네 번째 벤더로 추상화를 시험한다. P5·P6이 두 하네스 빌드, P7이 서버와 최소 로거다.

다음 시대부터 계획은 이 디렉터리에 독립 문서로 둡니다.
