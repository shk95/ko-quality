# 시대 98 — 저장소를 호스트 상태에서 떼어 내기 (끼어드는 시대)

공개 저장소의 기록이 빌드한 기기와 계정의 상태에 묶이지 않게 하고, 호스트에 쌓이는 데이터는 로컬에서만 규칙에 따라 관리되게 하는 시대입니다. 2026-09-18의 이력 재작성 두 번에서 드러난 문제를 받습니다.

**현재 위치:** `1-concept` 확인됨, `2-exploration` 작성됨 (2026-09-18). 제안 P-1~P-5가 사용자의 결정을 기다립니다. 시대 02는 `7-review` 전에 멈춰 있고, 이 시대가 `dev`에 머지된 뒤 재개합니다.

## 정식 시대와 다른 점

- **제품이 아니라 저장소 운영을 다룹니다.** 그래서 정식 번호 순서(01, 02, 03 …)에 넣지 않고, 진행 중인 시대 사이에 끼어듭니다.
- **일곱 단계를 모두 밟습니다.** 코드(로거, 코퍼스 생성기, 빌드 검사)를 바꾸므로 스펙, 계획, preflight가 필요합니다. 규모가 작으므로 각 단계는 가볍게 진행합니다.
- **앞 시대의 스펙을 고치지 않습니다.** 이 시대의 스펙이 시대 02 스펙(`09_toolkit_spec.md`)의 해당 절을 대체한다고 적고, 09에는 전방 포인터만 답니다.
- **`master` 머지는 리뷰에서 정합니다.** `master`는 리뷰를 거친 안정된 변경만 받습니다.
